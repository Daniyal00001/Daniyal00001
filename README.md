## 🚀 **Featured Projects**

### 1. [**GCU Learning Management System (LMS)**](https://lms.gcu.edu.pk/)

The university's live Campus Management System covering student enrollment, class/major changes, progress reports, assignment creation, and fee voucher generation. Serves 10,000+ students and staff with automated faculty billing, attendance tracking, eligibility checks, and CGPA-based grading.

- **Technologies**: Angular, Node.js, Express, MySQL

### 2. [**GCU Student Facilitation Center (SFC)**](https://sfc.gcu.edu.pk/)

A production portal supporting student service requests and facilitation workflows at GCU, maintained alongside the core LMS.

- **Technologies**: Node.js, Express, MySQL

### 3. [**GCU Societies Portal**](https://societies.gcu.edu.pk:10580/)

Platform for managing university society registrations, activities, and student engagement.

- **Technologies**: Node.js, Express, MySQL

### 4. [**SkillBridge — AI-Powered Freelance Marketplace (FYP)**](https://skillbridge.ddns.net/)

An AI-powered freelance platform connecting clients and freelancers through smart matching, eliminating manual proposal comparison. Features AI-assisted project scoping, negotiation, and cover letter generation, role-based access, real-time chat, blind reviews, Stripe-based escrow payments, and a bidding/skill-token system.

- **Technologies**: React, Node.js, Express, MongoDB, Python FastAPI, Socket.io

### 5. [**Health Connect**](https://health-connect-super.vercel.app/)

A role-based healthcare management system enabling admins, clinics, and front desk staff to manage doctors and patient records in real time with secure, HIPAA-compliant access control.

- **Technologies**: React, Node.js, Express, MySQL
- **Features**: Appointment booking, patient history tracking, payment management

### 6. [**The College Periodical**](https://www.thecollegeperiodical.com/)

A publishing platform for GCU students to submit journals and research papers through a blind, anonymous peer review system, with admin-controlled reviewer assignment and real-time submission-to-publication tracking.

- **Technologies**: Next.js, Node.js, MySQL

### 7. GCU Archive Portal

A digital archive system for GCU supporting structured storage and retrieval of institutional records.

- **Technologies**: React, Node.js, Express, MySQL

### 8. Leads Management System

- **Technologies**: Django, Django REST Framework
